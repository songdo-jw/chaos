이중진자 킥 제어 실험실

혼돈 운동 중인 이중진자에 작은 킥을 한 번 주어, 두 팔이 모두 위로 서는 목표(180°±15°)에 더 빨리 도달시킬 수 있는지 확인합니다. 회색은 킥 없는 진자, 색이 있는 것은 킥을 받은 진자입니다.

'최적 킥 시각 찾기'를 누르면 0~8초 사이 81개 시각을 모두 계산해 그립니다. 점선은 킥이 없을 때입니다.

보고서용 분석 그래프

보고서에 들어가는 세 가지 분석을 이 페이지에서 바로 계산합니다. 현재 설정한 에너지 값을 기준으로 하며, 그래프는 화면을 캡처해 보고서에 쓰면 됩니다.

버튼을 누르면 계산을 시작합니다. ②와 ③은 수백 번의 시뮬레이션이라 10~30초 정도 걸립니다.
